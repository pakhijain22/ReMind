# ReMind

### A Gamified Cognitive Wellness Platform for Dementia Care

ReMind is a web-based cognitive wellness platform designed to support people experiencing **dementia and cognitive decline** through simple, engaging, and accessible cognitive games.

The platform combines **technology, gamification, and cognitive exercises** to create an environment where users can regularly practice memory, attention, recognition, and problem-solving skills in an interactive way.

---

## 🌟 Features

* 🧠 **Cognitive Games**
  Interactive games designed around memory, attention, recognition, and logical thinking.

* 🎮 **Gamified Experience**
  Points, scores, progress and engaging interactions encourage regular participation.

* 📊 **Progress Tracking**
  Users can monitor their performance across different cognitive activities.

* 👴 **Dementia-Friendly Interface**
  Simple navigation, readable content, and an uncluttered interface designed with accessibility in mind.

* 🌏 **Culturally Relevant Experience**
  Incorporates familiar Indian/Northeastern cultural elements to make the experience more relatable and engaging.

* 📱 **Responsive Design**
  Works across desktops, tablets and mobile devices.

* 🔒 **User-Centric Design**
  Designed with simplicity, privacy and ease of use as key considerations.

* 📲 **PWA Support**
  ReMind can be configured as a Progressive Web App for an app-like experience.

---

## 🎯 Problem Statement

Dementia can affect memory, attention, recognition, communication and everyday cognitive abilities.

Many existing digital cognitive activities can be:

* Difficult for elderly users to navigate
* Repetitive or unengaging
* Not culturally familiar
* Difficult for caregivers to monitor
* Designed without sufficient consideration for accessibility

**ReMind aims to address these challenges by providing a simple and engaging digital platform for cognitive activities.**

---

## 💡 Our Solution

ReMind transforms cognitive exercises into an interactive experience.

Instead of presenting cognitive activities as conventional tests, the platform uses **gamification and familiar visual experiences** to encourage users to participate regularly.

The platform focuses on:

```text
Accessibility
     ↓
Engagement
     ↓
Cognitive Activities
     ↓
Performance Tracking
     ↓
Consistent Practice
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/pakhijain22/ReMind.git
```

### 2. Navigate to the project

```bash
cd ReMind
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
